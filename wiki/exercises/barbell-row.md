# Barbell Row（バーベル・ベントオーバーロウ）

Phase 2 背中重点版の**厚みの主砲**（2026-08-05 昇格決定、2026-08-25 器具確認・フォーム方針確定）。導入は Phase 2 開始時（W21 目安）。

## 現在地

**未導入**。較正スタート ~40 kg 目安（オリンピックバー 20 + プレート）。腰予算が詰まった場合のフォールバックはチェストサポーテッド DB ロウ（腰負荷ゼロ）。

## フォーム方針（2026-08-25 確定・僧帽型に固定）

「1種目1フォーム」の分担: 本種目 = **僧帽・上背の厚み型**。広背筋の広がりは [[lat-pulldown|ラットプルダウン]]、厚み下部はワンハンド DB ロウ（任意）が担当。

- グリップ広め（肩幅 + 拳1つ目安）・肘を横に張る（45-60°）
- **みぞおち〜胸下部に引き、トップで肩甲骨を寄せ切る**（一瞬止める）
- 前傾 30-45°・**セット中、上体角度を固定**

## 習得の勘所（腰痛歴持ち・出戻り文脈）

**本質は「RDL のボトムを固めたまま行うロウ」** — ヒンジは DL 80 / DB RDL で習得済みのため、ゼロからではなく「保持の練習」から入れる。

### 守るべき順（優先度順）

1. **腰のニュートラル死守**: 尻を後ろへ引くヒンジで前傾を作る（腰を丸めて屈まない）。腹圧をかけてから引き始め、セット中は maintain。**丸まりを感じたら即終了** — [[deadlift|DL]] と同じ規律
2. **上体角度を固定**: 最頻の崩れは「反動チート」— 股関節の伸展でバーを振り上げ、レップ毎に上体が起きていく。**上体が 15° 以上起きたらチートと判定**し、その重量は落とす
3. **バーは体から離さない**: 軌道は膝前をかすめてみぞおちへ。体から遠いほど腰のモーメントが増える（DL と同じ物理）
4. **腕で引かない**: 肘とその先は「フック」。肩甲骨を寄せる動きで引き始め、二頭・手首の力感が主になったら重すぎ
5. **すくめない**: 引く時に肩を耳に近づけない（シュラッグ化すると僧帽上部だけに逃げる）

### 習得プロトコル

| 段階 | 内容 |
|------|------|
| 導入 1-2 週 | **40 kg・3x8-10・RIR 3-4**。重量を追わずフォーム動画（側面）を撮って上体角度と腰のラインを確認 |
| 較正期 | ケーブルロウの LP 型（34→47 を8週）の再現を想定。「上体角度固定 + 腰ニュートラル」を満たすレップのみカウント |
| 反動対策オプション | 崩れが出たら**ペンドレイロウ化**（毎レップ床にデッドストップ）— 反動が物理的に入らず、毎レップ脊柱をリセットできる練習用変種 |

### 腰予算の運用

木 バーベルロウ + 金 DL/RDL は腰の累積負荷が重なる並び。**腰の疲労・違和感が続いたら主砲をチェストサポーテッド DB ロウに切替**（フォールバック常設・[[phase-2-hypertrophy-block|Phase 2]] に記載）。

## 漸進方針・注意

Phase 2 規定: 主軸 compound として rep 進捗優先（8 → 10 揃えで +2.5kg）。**フォーム品質がゲート** — 上体角度固定を破る重量は「持てても引けていない」と判定する。
