押し系の主種目。BIG3。

## 現在地（Week 13 終了時点）

**70 kg 3x8 RIR 2（作業重量、Week 14 から週2とも 70kg・本人決定）**。推定 1RM ~93 kg。65 → 67.5 → 70 と LP 継続中

### 読み取れること

1. **3ヶ月で working weight +30kg（40→70、+75%）**。推定 1RM は ~76 (5月末) → **~93 (現在)**。Muscle Memory による急速回復の教科書例
2. **転換点は 5月末の潰れ2連発** — 「昔の感覚」で計画を超過して2回失敗 → 計画遵守 + RIR 管理に切替えて以降、**挑戦重量以外で一度も失敗なし**
3. 6/15 以降は +2.5kg/1-2週の安定 LP。潰れは「計画された限界挑戦」(7/9, 7/12) のみで、どちらも次の週に適応で回収している
4. 推定 1RM ~93 は [[strength-roadmap|Strength Roadmap]] の「ベンチ 80kg (2026秋)」を前倒しで実質クリア、中級ライン 90kg も推定上は到達。**実測 1RM は Phase 3 のピーキング導入時に確認予定**
5. 次のマイルストーン: 70kg 週2 の定着 → 72.5kg (LP 継続) → 8月はカット終盤のため「維持できれば成功」の週も出る想定
