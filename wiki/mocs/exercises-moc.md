# Exercises MOC — 種目ハブ

負荷・方針を管理している種目のハブ。小物種目 (フェイスプル・サイドレイズ・カール等) は Phase 2 の Main 昇格時にページ化する。
入口: [[index|Wiki Index]]

- [[barbell-squat|BB スクワット]] — 脚の主種目。BIG3。
- [[deadlift|BB デッドリフト]] — ヒンジの主種目。BIG3。
- [[lat-pulldown|ラットプルダウン]] — プル重点日 (Upper B) の主種目。
