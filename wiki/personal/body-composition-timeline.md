## 5.4週間の変化サマリ（リコンプ第2ラウンド）

```
体重:     -0.3 kg  ← ほぼ横ばい
骨格筋量: +1.3 kg  ← ⭐ 名目ピーク超え（41.6 > 40.9）※午後測定の上振れ込み
脂肪量:   -2.7 kg  ← ⭐ ペース加速（-0.5kg/週）
ウエスト: -1.9 cm  ← 脂肪減の裏付け（測定条件に依存しない）
```

**カット中（実質 -400 kcal/日）のリコンプが2期連続で継続**。脂肪減はウエスト減で裏取りできており頑健。筋量増は方向として確実（挙上重量の全面漸進と整合）だが、+1.3 の幅は測定条件差（午後・体水分 +1.9L）を含むため、**実増は控えめに +0.5〜1.0 kg 圏と見るのが保守的な読み**。

### ロードマップとの照合（重要）

- **SMM ピーク超え（40.9）**: 計画「早ければ10月（バルク初月）」→ **名目上 8月中旬に前倒し達成**
- **LBM ピーク超え（71.6）**: 計画「バルク終盤 2027-01/02」→ **名目上5ヶ月前倒し**
- ただし上記の測定条件注意により、**正式認定は次回の午前・同条件測定で確認してから**（9月中旬の四半期評価が適地）
- 認定の如何にかかわらず、「カット中にここまで筋量が乗る」= Muscle Memory の残弾はまだ尽きていない

## 出戻り組への示唆

1. **リコンプは2期連続で継続する**（6週 +1.0/-2.1 → 5.4週 +1.3/-2.7）。出戻り組の Muscle Memory 残弾は「1ラウンドで尽きない」
2. **腕は Isolation なしでも戻り始めた**（プル系種目の急伸が効いた可能性）。Phase 2 の Isolation 導入でさらに上積みへ
3. **測定条件を揃えることの重要性**: 午後測定は TBW +1.9L で筋量が上振れする。マイルストーン判定は必ず同条件で
4. **体重目標はリコンプ下では形骸化する**: LBM が伸びる分だけ同 BF% の体重が重くなる。BF% + ウエスト + 写真で判定する
5. **骨ミネラル量はピーク超えを維持**: DL 漸進の継続効果
