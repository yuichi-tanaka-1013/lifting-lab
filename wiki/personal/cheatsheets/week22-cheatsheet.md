# Week 22 Cheat Sheet — Phase 2 第2週: ベンチのスキーム分割開始・DL 85・新種目の本較正・SQ 67.5 回収

> 週ナビ: ◀ 前週 [[week21-cheatsheet|Week 21]] | [[training-log-moc|Training Log MOC]] | 設計の大元: [[phase-2-hypertrophy-block|Phase 2 Hypertrophy Block]]

> W21 は 3/4（Day 4 のみ中止 = **新日順の狙い通り「落ちてよい枠」が落ちた初の実証** — 背中・ヒンジ・胸は無傷）。ベンチ 80 揃え = ピーク実質奪還・DL 82.5 上振れ・新種目6つ較正完了、と開幕週として満点。
> **今週のテーマ: (1) ベンチのスキーム分割開始 — Day 3 = 3x5 強度枠（82.5 較正）/ Day 1 = 3x8 ボリューム枠（77.5）、(2) DL 85 試行、(3) 較正済み新種目の本重量開始（RDL 50・ヒップスラスト 50・シュラッグ 24-26・リアデルト 6-8・DBショルダー 18 運用）、(4) SQ 67.5 の回収（Day 4）**。
> 日順 = 優先順（背中 → ヒンジ → 胸 → SQ）。連日弁: Day 1→2 連日なら DL は 82.5 据え置き + ロウをチェストサポーテッド化可。メンテ3週目 — **体重の週平均をご報告くだされ（今週末のバルク設計の材料）**。
> 📋 保留事項（報告があれば反映）: ①バーベルロウの「僧帽への効き」+ 動画 → あれば Day 1 は 42.5 / 未報告なら 40 でもう1週較正 ②ケーブルロウの「広背筋への効き」→ あれば Day 3 は 51.8 / 未報告なら 49.6 ③アダクターの扱い（それがしの進言 = 一旦外す。御裁定あるまで記載なし = 実施不要）。

> ロウ安全弁: 1セット目 RIR 2 未満 → 40。カール安全弁: 1セット目 10 未達 or RIR 0 → 14。

## Week 22 で失敗した場合の対処

| 状況 | 対処 |
|------|------|
| ベンチ 3x5 @82.5 1セット目 5rep 未達 or RIR 1 未満 | 80 に戻して残りセット |
| ベンチ 3x8 @77.5（Day 1）が RIR 1 以下にタイト化 | 75 に落とす（ボリューム枠で潰れない） |
| DL 85 1セット目 RIR 2 未満 or フォーム崩れ | 82.5 にドロップ。腰違和感即中止 |
| SQ 67.5 1セット目 RIR 2 未満 or 5rep 未達 | 65 にドロップ |
| RDL 50 / ヒップスラスト 50 で RIR 3 を大きく割る | 実測 RIR を報告 → W23 で刻み直し |
| バーベルロウ 40/42.5 で腰違和感 | 即終了 → チェストサポーテッド DB ロウ |
| フェイスプル 11.4 で肩がすくむ | 9.1 に即戻し（プリハブは品質が全て） |
| DBショルダー 18 でも 3セット目が 6 未満 | 16 x 3x8 に落として W23 再較正 |
| Day 1→2 連日 | DL 82.5 据え置き + ロウのチェストサポーテッド化可 |
| 週3しか取れない | Day 4 を落とす（SQ 67.5 は W23 へ。2週連続なら救済策を相談） |
| 全体的に疲労蓄積 | 増量試行を全て中止して前週重量・オプションカット |
