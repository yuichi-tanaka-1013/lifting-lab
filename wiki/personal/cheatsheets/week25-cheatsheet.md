# Week 25 Cheat Sheet — 🔄 復帰週（約2.5週の休止明け・首の付け根の凝りケア付き）

> 週ナビ: ◀ 前週 [[week23-cheatsheet|Week 23（未消化）]] | [[training-log-moc|Training Log MOC]]

> **経緯**: 9/26 を最後に約2.5週休止（首の付け根の強烈な凝り）。原因は**両仮説併記**（[[hypotheses|Hypothesis 3]]）: 本人仮説 = ストレス・姿勢由来（**既往あり** — トレと無関係の時期にも発生）/ 老中の当初仮説 = 僧帽上部ボリューム急増（タイミングの一致のみ）。**W25-26 の復帰が自然実験** — シュラッグ休止のまま再開し、凝りの再発有無（/10）を毎セッション記録して切り分ける。W23 は未消化のまま失効。10/13 から再開。
> **復帰週の三原則**: ①全種目 -1 段（約 -5〜10%）・**今週は増量ゼロ・揃え専念**（W26 から漸進再開）②**シュラッグ休止・フェイスプル 9.1 に戻す・全種目「肩をすくめない」最優先** ③凝りの再発・腕への痺れ・放散痛が出たら**その場で中止して報告**（痺れ・放散痛は整形外科案件）。
> 日順 = 優先順（背中 → ヒンジ → 胸 → SQ）は維持。レッグプレスは Day 2 常設（W23 で導入済みの救済策）。
> 食事はメンテ継続（トレ日 2.3合 / 休息日 1.7合）。**バルク開始は復帰2週の安定を確認してから（10月末目安）に延期**。

## Week 25 で失敗した場合の対処

| 状況 | 対処 |
|------|------|
| **首の凝りが再発（トレ中）** | その種目を終了して報告。ロウ系ならチェストサポーテッド化を検討 |
| **腕への痺れ・放散痛・頭痛** | **セッション中止 → 整形外科**（トレより先） |
| 1段戻しでも RIR が想定より低い | さらに1段戻す（ブランクの個体差 — 恥ではない） |
| 1段戻しが軽すぎる（RIR 5+） | それでも今週は上げない — 結合組織と作業耐性の週 |
| 週3しか取れない | Day 4 を落とす（従来通り） |
