# Week 21 Cheat Sheet — 🔱 Phase 2 開幕（背中重点・移行週）: 日順 = 優先順の新配置で、背中が週頭に立つ

> 週ナビ: ◀ 前週 [[week20-cheatsheet|Week 20]] | [[training-log-moc|Training Log MOC]] | 設計の大元: [[phase-2-hypertrophy-block|Phase 2 Hypertrophy Block]]

> **今週から2つの大転換**: ①Phase 2（背中重点）開幕 — ただし「移行週」として新種目の較正と進行中の昇格を分離（フル Phase 2 レンジは W22 から）②**日順 = 優先順の新配置（本人要件 9/13）** — 週頭から空いた日に詰める方式に合わせ、**Day 1 = 背中 → Day 2 = ヒンジ（DL）→ Day 3 = 胸 → Day 4 = SQ** の順で消化。忙しい週は後ろから落ちる設計（週3なら SQ 日が落ち、背中・DL・胸は無傷。週2でも背面コンプリートが残る）。足は Day 2・4 で非隣接。
> 開始日 = 週の最初に空いた日から Day 1 を順に。メンテ食2週目（トレ日 2.3合 / 休息日 1.7合・体重は週平均で記録開始）。
> ⚠️ **Day 1 → Day 2 が連日（中0日）になる場合の弁**: ①Day 1 のバーベルロウをチェストサポーテッド DB ロウに置換（腰の等尺ゼロ化）②**DL は 82.5 試行をやめ 80 据え置きに切替**（初挑戦を連日で打たない — 所見10）。

## Week 21 で失敗した場合の対処

| 状況 | 対処 |
|------|------|
| ベンチ 80 がまた潰れ（3露出目） | 想定内。W22 に「77.5 へ一段下げて揃え直すか」を相談（無限に潰れを重ねない） |
| バーベルロウ 40 で腰に違和感 | その場で終了 → 次回チェストサポーテッド DB ロウ（正規フォールバック） |
| Day 1 → Day 2 が連日 | ロウをチェストサポーテッド化 or RDL 削減 + **DL は 80 据え置き** |
| DL 82.5 1セット目 RIR 2 未満 or フォーム崩れ | 80 にドロップ。腰違和感即中止 |
| SQ 67.5 1セット目 RIR 2 未満 or 5rep 未達 | 65 にドロップ |
| ラットプル / ロウ / カール の1セット目安全弁 | 66 / 49.6 / 14 に戻す |
| レッグカール 50 x 3x12 1セット目 10 未達 | 45 x 3x12 |
| 新種目の較正が重すぎ/軽すぎ | その場で調整して実測値を報告 — W22 で確定 |
| Day 2 の腰が重い | ヒップスラストを次週へ |
| **週3しか取れない** | **Day 4（SQ 日）を落とす — 背中・DL・胸は無傷（新設計の狙い通り）** |
| 週2しか取れない | Day 1-2 のみ = 背面コンプリートが残る |
| 全体的に疲労蓄積 | 新種目の較正だけ残しオプション全カット |
