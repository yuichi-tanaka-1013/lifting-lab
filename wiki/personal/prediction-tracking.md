# Prediction Tracking — 予測 vs 実績の答え合わせ

チートシートに書かれた計画予測 (目標 RIR・見込み rep) と実績のズレを蓄積し、**計画者の較正 (calibration) 個人係数**を作る。/log-workout のたびにここへ1行追記する運用。

判定: **的中** = 予測レンジ内 / **上振れ** = 実績が予測より楽 (計画が保守的) / **下振れ** = 実績が予測よりきつい (計画が楽観的)

## 現時点の較正所見 (n=15)

1. **押し系メイン (ベンチ・SQ・DL) はほぼ較正済み** — 的中率高い。安全弁の発動もゼロ。重量設定の精度は信頼してよい
2. **プル系・カーフの計画は一貫して保守的すぎる** (ロウ 2週連続上振れ、カーフ特大上振れ) → **これらの種目は増量の刻みを1段早めてよい**、が現時点の個人係数
3. **下振れは全て「疲労文脈」で説明がつく** — サイドレイズ (ベンチ70直後)、ラットプル (増量週)、ブルガリアン左 (弱点部位)、プランク (セッション終盤+連日)。重量ミスマッチによる下振れはゼロ → 計画が外れるときは「順序と疲労」を疑う
4. 初挑戦系 (70 ベンチ・70 DL) はいずれも予測より上に出た — **休養明けのフレッシュ状態を予測が過小評価**する傾向
